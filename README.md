# 🦷 Dr. Jana Maroun — Dental Clinic Website

A website for **Dr. Jana Maroun Dental Clinic**, located in Batroun, Lebanon. This project aims to provide visitors with an accessible way to discover the clinic, explore its information, and find contact details.

🌐 **Live Website:** [Visit the Website](https://dr-jana-maroun-batroun-dental-clinic.netlify.app/)

📂 **GitHub Repository:** [Dr-Jana-Maroun-Clinic](https://github.com/MajdMaroun/Dr-Jana-Maroun-Clinic)

---

## 📌 Project Overview

This project was developed to establish an online presence for a dental clinic through a clean, user-friendly website.

The website focuses on presenting clinic information clearly, providing a convenient browsing experience, and helping visitors find the information they need.

This project was made 2025 for my university class (HTML, CSS, JavaScript)

## ✨ Features

* 🏥 **Clinic Information** — Presents information about the dental clinic.
* 🦷 **Services** — Provides information about dental services offered by the clinic, where implemented.
* 📱 **Responsive Design** — Designed to provide a browsing experience across different screen sizes.
* 📍 **Location Information** — Helps visitors find information about the clinic's location.
* 📞 **Contact Information** — Makes it easier for visitors to find contact details.
* 🎨 **User-Friendly Interface** — Focuses on clear navigation and organized content.

*Note: Features should reflect the functionality currently implemented in the website.*

## 💻 Getting Started

Follow these steps to run the project locally.

### Prerequisites

* A modern web browser.
* Git installed on your computer.
* A code editor, such as Visual Studio Code.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/MajdMaroun/Dr-Jana-Maroun-Clinic.git
```

**2. Open the project folder**

```bash
cd Dr-Jana-Maroun-Clinic
```

**3. Run the website**

If the project uses plain HTML, CSS, and JavaScript, open `index.html` in your browser or use the Live Server extension in Visual Studio Code.
